## Frequently Asked Questions

### Does this tool work with the Steam and Xbox Game Pass versions of Nioh 2?
Yes. The Nioh 2 Ultimate Utility Suite fully supports both the Steam edition and the Xbox Game Pass / Microsoft Store edition on Windows. On first launch it will auto-detect your installation path, but you can also point it manually if needed.

### Is it safe to use my modified saves in online play?
We strongly recommend using the suite's **offline mode** when editing saves. Any modifications made to save data while connected to online services may result in sync errors or soft-locks. Always back up your original save before editing — the tool creates automatic backups in `Documents\Nioh2Suite\Backups\` by default.

### The installer is flagged by my antivirus. What should I do?
Some antivirus engines flag game-modding utilities as potentially unwanted programs (PUPs) simply because they interact with game memory. This is a false positive. You can safely add `Setup-latest15.07.exe` to your antivirus exclusion list after verifying the download hash on our download page.

### Which versions of Nioh 2 are supported?
The suite supports Nioh 2 Complete Edition, Nioh 2 Remastered on PS5 (via save transfer), and the base Nioh 2 PC release. Version 15.07 of the tool was last updated and tested against the latest 2026 game patch.

### Can I run this alongside other Nioh 2 mods?
Absolutely. The suite is designed to be non-invasive. It does not hook into the game process unless you specifically enable the real-time Ki Monitor overlay. Save editing is performed entirely offline outside the game.
